# flyattn — does the fly's geometry buy an attention layer anything?

A standalone research project (independent of the XCAP pipeline in the rest of
this repository) testing whether the FlyWire connectome's hyperbolic geometry
carries anything transferable to attention architectures.

The program is pre-registered against a null: `conn2res` found nothing for the
fly, Frankle et al. found mask position irrelevant at init, and the ESA advantage
lives in one corner of hyperparameter space. Most of this is expected to come
back negative; the value is in knowing **which** part fails and why.

## Data — real, public, no substitutes

| what | source |
|---|---|
| FlyWire v783 connectome | Codex public snapshot (Dorkenwald et al. 2024; Schlegel et al. 2024) |
| Project Gutenberg / Brown / Reuters | NLTK corpora |

`scripts/fetch_data.sh` pulls both. The connectome is used at the >=5-synapse
threshold with per-neuropil rows aggregated: 134,181 neurons and 2,700,513
directed edges, 0.028% undirected density.

## House rules

* The baseline is a **degree-preserving rewiring** or a **hot-limit S1/H2
  sample**. Never Erdos-Renyi, never "random".
* Never report in-distribution loss alone. Every training run reports the
  sample-efficiency curve, a hard-token subset, and three OOD corpora at
  increasing distance.
* Report **interactions** with criticality and data scale, not main effects.
* Byte-level tokenisation, so OOD numbers are not tokeniser artefacts.

## Layout

```
src/flyattn/
  connectome.py   FlyWire loading, thresholding, graph construction
  nulls.py        vectorised degree-preserving rewiring (directed + undirected)
  s1h2.py         S1/H2 sampling, hidden-degree calibration, beta and gamma fits
  curvature.py    Balanced Forman curvature and SDRF
  masks.py        attention masks along the temperature axis, global-token masks
  model.py        the MoE-MHA baseline and its switches
  train.py        shared training/eval harness
  textdata.py     corpora and the OOD split
  synth.py        MQAR and gap-recall
scripts/          one script per experiment; results land in results/*.json
RESULTS.md        generated by scripts/report.py
```

## Experiments

| id | question | script |
|---|---|---|
| M1 | what inverse temperature beta does FlyWire sit at? | `m1_temperature.py` |
| M2 | is the connectome more negatively curved than its degree-matched null? | `m2_curvature.py` |
| M3 | how many neurons are actually in/out asymmetric? | `m3_richclub.py` |
| T1 | at what density does weight *position* start to matter? | `t1_pruning.py`, `t1b_finetune.py` |
| T2 | is Euclidean-distance attention anything but a per-key bias? | `t2_keybias.py` |
| T3 | is there an optimum in beta, and does the fly sit at it? | `sweep.py --grid t3` |
| T4 | does structure interact with the QK-init criticality axis? | `sweep.py --grid t4` |
| T5 | does mask curvature predict long-range failure, and does SDRF fix it? | `t5_curvature_surgery.py` |

## Running

```bash
python3 -m venv .venv && .venv/bin/pip install numpy scipy torch
scripts/fetch_data.sh
.venv/bin/python scripts/m1_temperature.py
.venv/bin/python scripts/report.py       # regenerates RESULTS.md
```

Everything here was run on 4 CPU cores with no GPU, which sets the scale of the
training arms: ~2M-parameter MoE-MHA models, 1.5k-6k steps. Effect sizes are
reported with seed spread so the reader can see what that buys.
